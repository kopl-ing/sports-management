# Sports management

Per-sport behaviour (field rows, keeper zone, sanctions, scoring, rule defaults) lives in `src/Sport/{Sport}.php` (`SportConfig`); numbers live on the seeded format presets (`players_on_field`, `play_minutes`, `breaks`, `rules` JSON overriding the config's defaults), one seeder per federation extending `Command/SeedsFormatPresets`. Adding a sport = a `Sport` case + config class + seeder, never a branch in the tracker. Words that differ per sport go through `$sport->trans($key)` with a `by_sport.{sport}.{key}` override only in the language that needs it — never a sport check in a view. Team staff are coaches or referees: `Team::isStaffedBy()` only means "may open the team"; gate coach-only actions on `Team::isCoachedBy()` and anything a referee can be delegated on `TeamMatch::handles($person, RefereeDuty)` (details in the plan's "Where we left off"). Match event tables (substitutions, goals, sanctions) keep microsecond timestamps (`$dateFormat`): same-offset events replay in `created_at` order, so a new event table needs the same. Status and open points: `.docs/planning/sports-management-extension-plan.md` ("Where we left off") and `.docs/planning/sports-management-multi-sport-epic.md`.
